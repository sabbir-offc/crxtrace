# Security Policy

## Supported versions

CrxTrace is pre-1.0. Security fixes land on the latest published minor version
only. Once 1.0 ships, this table will list a supported range.

| Version | Supported |
| --- | --- |
| 0.1.x | ✅ |

## Reporting a vulnerability

**Please do not open a public issue for a security problem.**

Use GitHub's private vulnerability reporting instead:

> **[Report a vulnerability](https://github.com/sabbir-offc/crxtrace/security/advisories/new)**
> — or go to the repository's **Security** tab → *Report a vulnerability*.

This creates a private advisory only you and the maintainers can see.

You should get an acknowledgement within 72 hours. If a fix is warranted, I'll
work with you on a disclosure timeline — the default is a patched release
followed by a public advisory crediting you, unless you'd rather not be named.

## What's in scope

This library runs inside other people's browser extensions and handles data
from pages the user never chose to share. The failures that matter most:

- **Data leaking past redaction** — a token, credential, or PII shape that
  [`redact.ts`](src/redact.ts) fails to scrub before the event is sent.
- **Reporting another site's errors** — the `inApp` stack-frame check in
  [`stacktrace.ts`](src/stacktrace.ts) is what keeps a host page's own
  exceptions (and its stack traces) out of your server. A bypass is a serious
  bug.
- **Sending to an unintended origin** — anything that causes an envelope to
  reach a host other than the configured `dsn`.
- **Storage poisoning** — a crafted event that corrupts the durable queue such
  that unrelated events are lost, duplicated, or misattributed.
- **Prototype pollution or injection** via captured error data or breadcrumbs.

## What's out of scope

- Vulnerabilities in an extension that *uses* CrxTrace, but not caused by it.
- The behaviour of a self-hosted ingest endpoint you wrote.
- Missing hardening that requires an option the user must deliberately turn on
  (e.g. `sendDefaultPii: true` sending query strings — that is documented and
  intentional).
- Reports generated by automated scanners with no demonstrated impact.
