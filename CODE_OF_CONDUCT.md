# Code of Conduct

## The short version

Be decent to people. Assume good faith. Critique code, not the person who
wrote it.

## Our standards

Things that make this project better:

- Being welcoming to people at any level of experience, and remembering that a
  "basic" question is only basic once you already know the answer
- Giving and accepting review feedback on the technical merits
- Being clear about the difference between "this is wrong" and "I would have
  done it differently"
- Owning mistakes and correcting them

Things that are not acceptable:

- Harassment, insults, or personal attacks, public or private
- Sexualised language or imagery, or unwelcome advances
- Publishing anyone's private information without explicit permission
- Sustained disruption of discussions, or bad-faith argument

## Scope

This applies in every project space — issues, pull requests, discussions,
commit messages, code comments — and whenever someone is representing the
project in public.

## Enforcement

Report a problem by sending a private message to
[@sabbir-offc](https://github.com/sabbir-offc), or via GitHub's
[report abuse](https://github.com/contact/report-abuse) flow if the situation
involves the maintainer.

Reports are handled privately. The reporter's identity is not shared with the
person reported. Depending on severity, the response ranges from a private
word, to a warning, to a temporary or permanent ban from project spaces.

Maintainers who do not enforce this in good faith may face consequences from
the project's leadership.
